## 🌟 插件核心特性与功能总结

本插件专为 **fnOS（飞牛私有云操作系统）** 官方音乐服务（`trim.music`）量身定制，采用先进的 **Unix Socket 零侵入劫持与反向代理架构**，不修改官方二进制、不破坏官方数据库，完全解耦第三方独立容器，实现全平台（Web 端、飞牛官方 App、第三方客户端）无缝增强。

### 1. 🎵 全网音源聚合与无损解析
- **五大主流平台直连**：原生深度支持 **网易云音乐 (wy)**、**酷我音乐 (kw)**、**酷狗音乐 (kg)**、**QQ 音乐 (tx)**、**咪咕音乐 (mg)**。
- **真·无损音频流 (SQ / FLAC)**：优先解析 24bit/96kHz、16bit/44.1kHz FLAC 原画母带音质，杜绝低码率欺骗。
- **独立 Node.js 沙箱引擎**：内置轻量化原生解析引擎，彻底脱离落雪服务容器（9528/8772），资源占用极低。
- **智能故障转移 (Failover)**：当主音源无版权或失效时，自动毫秒级跨源切换可用音源起播。

### 2. 💎 封面、逐字歌词与歌曲信息完善体系
- **多源封面深挖与 500px 高清升级**：自动修复酷我等接口的文本型封面与 120px 缩略图，一律重定向至 500px 原画大图，杜绝客户端灰块与裂图。
- **逐字同步动态歌词**：支持精准对齐时间戳的 LRC 歌词抓取，全屏播放视图与歌词面板实时滚动。
- **Now Playing（全屏播放详情）元数据补齐**：自动补全完整的歌手对象、专辑对象与音频规格（audioSpec），彻底消除“加载失败”提示。

### 3. 💾 智能边播边存（无感离线）
- **Tee（三通）流式管道架构**：在线试听时后台自动通过流式 chunk 写入本地缓存，不耗费额外流量、不阻塞前端播放。
- **本地秒开与进度条零拖拽延迟**：再次播放该曲目时直接由本地磁盘提供 HTTP 206 分片服务，零外网流量消耗。
- **自动内嵌标签**：缓存落盘时自动写入 ID3 歌曲名、歌手、专辑标签，并配套生成同名 `.lrc` 歌词。
- **LRU 缓存容量智能管控**：支持在后台自定义最大缓存容量上限（MB），超出上限时按时间由旧到新自动修剪试听音频，保护系统磁盘。

### 4. 🚀 丰富的在线交互界面与排版优化
- **在线歌单广场**：侧边栏直通五大主流平台精选歌单，卡片式网格流展示，支持一键起播与整单导入。
- **官方排行榜实时注入**：酷我/网易云热歌榜、新歌榜、飙升榜自动注入飞牛歌单体系。
- **独立「下载」管理导航**：左侧侧边栏专属「下载」入口，完全解耦本地媒体库，记录在线下载状态（成功/失败/重试）并支持物理单曲删除。
- **1060px 黄金播放控制栏**：定制修长毛玻璃控制栏，集成精致音质下拉菜单（标准/极高/无损/超清母带等），全图标完美嵌合。

### 5. 🤖 飞牛音乐 AI 音乐助手
- **听歌偏好与风格分析**：直连本地 SQLite 数据库分析用户播放记录与红心收藏。
- **心动歌曲推荐**：支持用户自定义 OpenAI 兼容协议的大语言模型（如 DeepSeek、商汤日日新、OpenAI 等），生成个性化推荐并在首页挂载「💖 我的心动歌曲推荐」卡片。

### 6. 🛡️ 系统级高可用与自愈机制 (Watchdog)
- **毫秒级状态感知**：独立后台守护进程每 3 秒检测官方服务与前端补丁状态。
- **断线秒级自愈**：飞牛官方升级或重启导致覆盖静态资源或夺取 Socket 时，守护进程自动秒级重新接管并恢复全量增强功能。

## 🚀 安装与使用指引（全新设备导入）

### 前置条件
1. 设备已安装 **fnOS（飞牛私有云系统）**；
2. 已在 fnOS「应用中心」安装并启动了官方 **【飞牛音乐】** 应用；
3. 系统具备基本的 `python3`、`python3-venv` 与 `curl`。

### 一键安装步骤
1. 将插件压缩包 `fnos_music_ext_v1.3.1_standalone.tar.gz` 上传或解压至目标 NAS（如 `/vol1/1000/beifen/fnos_plug/`）；
2. 进入插件目录，执行一键安装脚本：
   ```bash
   sudo bash install.sh
   ```
3. 脚本会自动完成以下操作：
   - 探测飞牛官方音乐服务目录；
   - 建立独立的 Python 虚拟运行环境并安装轻量依赖；
   - 注入前端全量定制补丁与高清图标；
   - 注册并启动 `fnmusic-ext.service` 与 `fnmusic-watchdog.service` 系统守护服务。
4. 安装完成后，在电脑或手机浏览器打开飞牛音乐，按 **Ctrl + F5** 强制刷新，即可开启全新无损音乐体验！

## ⚙️ 扩展配置与后台管理

安装完成后，打开浏览器访问专属后台控制中心：
👉 **`http://<您的 NAS IP>:5666/music/ext/`**

在后台管理面板中，您可以自由进行以下配置：
1. **系统概览**：实时直通飞牛官方原生媒体库数据，查看曲库歌曲数、专辑数、歌手数及红心收藏。
2. **飞牛音乐 AI 助手**：填入您自己的大模型 API Key 与 Base URL，配置专属心动推荐模型。
3. **排行榜与歌单管理**：自由勾选想要同步到飞牛音乐中的各大平台排行榜及一键导入外部歌单。
4. **自定义音源**：导入或切换落雪格式的第三方音源脚本（支持上传 `.js` 文件）。
5. **缓存与下载中心**：配置最大缓存上限（MB）与 NAS 离线下载保存目录。
6. **WebDAV 云端备份**：配置 WebDAV 账户，定时自动将歌单、配置与数据库快照备份至云盘。

## 🔄 一键卸载与还原

若需要完全恢复飞牛音乐官方出厂初始状态，只需在插件目录下执行：
```bash
sudo bash uninstall.sh
```
脚本将自动停止扩展服务并恢复官方前端静态资源。
